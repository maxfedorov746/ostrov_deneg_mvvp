# «Остров Денег»: пояснение к исходному коду

Документ относится к архиву `ostrov-deneg-source-for-github.zip`. После распаковки в папке `ostrov-deneg` находятся исходники, готовая сборка интерфейса для демонстрации и инструкции запуска.

## Как проходит действие пользователя

Браузер показывает интерфейс React из `frontend/src`. При регистрации, выборе бюджета, сохранении записи или сценария он отправляет запрос в FastAPI. Сервер проверяет входные данные и права пользователя, сохраняет действие в базе, передаёт агрегированные суммы в игровой движок и возвращает новое состояние острова. Интерфейс обновляет рисунок, показатели и пояснение. Денежные суммы передаются в **целых копейках**; отказ от покупки не уменьшает остаток бюджета.

## Что важно при изменениях

1. Меняйте расчёты в `island_engine/engine.py` и проверяйте связанные тесты в `backend/tests/test_engine.py`. Движок получает уже подготовленные суммы и не должен читать базу сам.
2. При добавлении поля записи обновите `schemas.py`, `models.py`, API, новую миграцию Alembic и типы в `frontend/src/lib/api.ts`. Существующие миграции не переписывайте после публикации.
3. После правки React-кода соберите фронтенд заново и обновите `demo-web/`; иначе запуск через `start-demo` покажет старую версию интерфейса.
4. Публичный эндпоинт острова друга должен возвращать только разрешённую модель: без контакта, возраста, бюджета, сумм и списка операций.
5. `.env` и `.local-data` содержат локальные настройки, секрет и пользовательскую базу. Они исключены через `.gitignore` и не должны попадать на GitHub.

## Как проверить

Для простого просмотра в Windows распакуйте архив, установите Python 3.12 или новее и запустите `start-demo.bat`. Первый запуск требует интернета для установки пакетов. Затем откройте `http://127.0.0.1:8080/`.

Для проверки серверных тестов из папки `backend`: `python -m pytest -q` после установки зависимостей из `backend/requirements.txt`. Для проверки исходного интерфейса из папки `frontend`: `npm install`, затем `npm run build`. Основной способ запуска с PostgreSQL описан в `README.md`.

## Ограничения текущей версии

Это MVP: нет банковской интеграции и реальных платежей. Согласие родителя реализовано как демонстрационный экран с чекбоксом, а не как подтверждённая юридическая процедура. Локальный запуск использует SQLite; конфигурация Docker использует PostgreSQL. Перед публичным размещением потребуются отдельные проверки развёртывания, безопасности и обработки персональных данных.
